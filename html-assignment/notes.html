5 HTML tags I have learnt

The tag: <dl>
It defines a description list. It works in conjunction with <dt> and <dd>. It is useful for things like Q&A.
The tag: <strong>
It is used to make words appear bold when displayed. It's outdated version is <b>
The tag: <div>
It is used as a container for HTML elements and can be styled with CSS. It can easily be styled using the class or id attribute. SOURCE
The tag: <section>
It defines a section in a document.
The tag: <article>
The tag specifies independent, self-contained content. It tag does not render as anything special in a browser but it can be styles using CSS. SOURCE
